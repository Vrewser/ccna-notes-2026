# Point-to-Point OSPF Networks

---

## The Network Command Syntax
* `nework network-address wildcard-mask area area-id`

* The *network-address wildcard-mask* is used to enable OSPF on interfaces. Any interfaces on a router that match the network address in the **network** command are enabled to send and receive OSPF packets.
* The **area** *area-id* syntax refers to the OSPF area. The network command must be configured with the same area-id value on all routers.
    * It is good practice to use an area ID of 0 with a single-area OSPFv2. Makes it easier if the network is later altered to support multiarea OSPFv2.

---

## The Wildcard Mask
* Is typically the inverse of the subnet mask configured on that interface.
* For subnet mask, binary 1 is equal to a match and binary 0 is not a match. **The reverse is true for wildcard masks**.

## Configure OSPF using the ip ospf command
`ip ospf process-id area area-id`

---

## Passive Interface
* OSPF messages only need to be sending out interfaces that are connecting to other OSPF-enabled routers.

1. **Inefficient Use of Bandwidth**
    * Available bandwidth is consumed transporting unnecessary messages.
2. **Inefficient Use of Resources**
    * All devices on the LAN must process and eventually discard t he message.
3. **Increased Security Risk**
    * OSPF messages can be intercepted with packet sniffing software without additional OSPF security configurations.

---

## Configure Passive Interfaces
* Use the `passive-interface` router configuration mode command to prevent the transmission of routing messages through a router interface, but still allow that network to be advertised to other routers.

---

## OSPF Point-to-Point Networks

**To verify if routers elected a DR and BDR use the command:**
    * `show ip ospf interface`

**To disable the DR/DBR election process use the command:**
    * `ip ospf network point-to-point`
    * (NOTE: This will turn the network type from BROADCAST to POINT_TO_POINT)
