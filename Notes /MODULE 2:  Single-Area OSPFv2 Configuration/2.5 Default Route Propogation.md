# Default Router Propogation

---

## Propogate a Default Static Route in OSPFv2
* Network users will need to send packets out of the network to non-OSPF networks, like the internet.

**Autonomous System Boundary Router (ASBR)**
* The router located between an OSPF routing domain or the gateway router.

---

## To propogate a default route:
* To configure, use the following:
    * A default static route using the `ip route 0.0.0.0 0.0.0.0 [next-hop-address | exit-intf]` command.
    * To instruct a router to be the source of the default route information and propogate the default static route in OSPF updates, use: `default-information originate` command.
