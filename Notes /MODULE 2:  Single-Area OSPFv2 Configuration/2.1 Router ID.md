## Router IDs
* An OSPF router ID is a 32-bit value, represented as an IPv4 Address.
* The Router ID is used to uniquely identify an OSPF router.

1. **Participate in the synchronization of OSPF databases**
    * During the Exchange State, the router with the highest Router ID will send their database descriptor (DBD) first.
2. **Participate in the election of the designated router (DR)**
    * In a multiaccess LAN environment, the router with the highest Router ID is elected as Designated Router (DR).
    * The second router with the highes RID becomes the Backup Designated Router (BDR).

---

## Router ID Order of Precedence
* But how does the router determine the router ID?

1. The router ID is explicitly configured using the OSPF `router-id`. Used to administratively assign the RID to a router.
2. If the router ID is not explicitly configured, the router chooses the highest IPv4 address on any of the configured loopback interfaces.
3. If no loopback interfaces are configured, the router chooses the highest active IPv4 address. *(Least recommended method.)*

---

## Configure a Loopback Interface as the Router ID
* Instead of relying on physical interface, the Router ID is configured into a loopback interface.

---

## Modify a Router ID
* After a router selects a router ID, an active OSPF router does not allow the Router ID to be changed until the router is reloaded or the OSPF process is reset.

**In order to reload the router / reset the OSPF process:**
* Use `clear ip ospf process`

**To Verify if the router is using the new Router ID:**
* Use `show ip protocols`
