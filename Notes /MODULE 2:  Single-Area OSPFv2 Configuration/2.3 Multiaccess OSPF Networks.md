# Multiaccess OSPF Networks

---

## Multiaccess OSPF Networks
* Are unique in that one router controls the distribution of LSAs.

---

## Verify DR/BDR Adjacencies
* To verify the OSPFv2 adjacencies, use the `show ip ospf neighbor` command.

1. **FULL/DROTHER**
    * A DR or BDR Router that is fully adjacent with a non-DR or BDR Router. These two neighbors can exchange Hello packets, updates, queries, replies, and acknowledgements.
2. **FULL/DR**
    * The Router is fully adjacent with the indicated DR neighbor. Same exchange sequence as the previous.
3. **FULL/BDR**
    * The Router is fully adjacent with the indicated BDR neighbor. Same exchange sequence as the first.
4. **2-WAY/DROTHER**
    * The non-DR or BDR Router has a neighbor relationship with anoter non-DR or BDR router. *These two neighbors exchange Hello Packets.*

---

## Default DR/BDR Election Process
* Router elects the router with the highest interface priority as DR, second highest is elected as BDR. If the interface priority value is 0 - that interface cannot be elected as DR nor BDR.
* If the interfaces are equal, the router with the highest router ID is elected as the DR. The second highest router ID will be the BDR.

**LONG STORY SHORT: Router ID is the tie breaker**

*Note: The addition of a new router does not initiate a new election process.*

---

## DR Failure and Recovery
* If the DR fails, the BDR is automatically promoted to DR. Doesn't matter if there's a new higher priority router / the previous DR router re-joins. It stays with the newly elected DR.
* After the promotion, a new BDR is elected as well.

---

## Configure OSPF Priority
* The `ip ospf priority` command will be used to change the DR and BDR.
