# CCNA Notes (2026)

Simple, expandable note repository for CCNA study.

## Quick start

1. Open the main index: [notes/README.md](notes/README.md)
2. Pick a domain folder
3. Add or update note files with your own titles/content

## Structure

- `notes/README.md` → main navigation page
- `notes/_template.md` → reusable template for new note pages
- `notes/<domain>/README.md` → domain landing pages
